# Luther's Werke

> Welcome to the complete digital repository for the Erlanger Edition of Luther’s Werke.

This project hosts all 105 historical volumes—comprising the 67 German and 38 Latin texts—making over 50,000 pages of primary source material fully searchable, retrievable, and translatable through an interactive AI interface. Designed for readers who want to extract clean, unadulterated historical texts, print specific scripture portions, or synthesize Luther's fragmented teachings on any theological topic.
